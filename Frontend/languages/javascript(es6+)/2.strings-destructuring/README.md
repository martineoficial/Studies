**Lição 2: Template Literals e Desestruturação (`Destructuring`)**

- **Tema:** Manipulação elegante de strings e extração de dados.
- **Objetivo:** Utilizar `Template Literals` para strings mais dinâmicas e `Destructuring` para extrair dados de objetos e arrays de forma limpa.
- **Conteúdo:**
    - Interpolação de strings, multilinhas com `Template Literals`.
    - Desestruturação de objetos (renomear, valores padrão).
    - Desestruturação de arrays (ignorando elementos, rest pattern).
- **Repositório:** `2.strings-destructuring`
- **Estrutura:** `index.html`, `src/lesson2.js`.
