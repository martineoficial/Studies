**Lição 8: Métodos de Array Avançados (`reduce`, `find`, `some`, `every`)**

- **Tema:** Operações de agregação e busca mais complexas em arrays.
- **Objetivo:** Aprofundar nos métodos de array para realizar somas, agrupamentos, buscas e verificações condicionais.
- **Conteúdo:**
    - `reduce()`: Agregação de valores, transformações complexas.
    - `find()`: Encontrar o primeiro elemento que satisfaz uma condição.
    - `some()`: Verificar se *pelo menos um* elemento satisfaz.
    - `every()`: Verificar se *todos* os elementos satisfazem.
- **Repositório:** `8.array-methods-part2`
- **Estrutura:** `index.html`, `src/lesson8.js` (exemplos com dados mais complexos).
