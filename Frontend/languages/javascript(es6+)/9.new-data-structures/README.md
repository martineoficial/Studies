**Lição 9: Novas Estruturas de Dados (`Set` e `Map`)**

- **Tema:** Introdução a coleções de dados modernas e suas aplicações.
- **Objetivo:** Entender e utilizar `Set` para coleções de valores únicos e `Map` para pares chave-valor flexíveis.
- **Conteúdo:**
    - `Set`: Para remover duplicatas, verificar existência de elementos.
    - `Map`: Armazenar pares chave-valor onde a chave pode ser qualquer tipo.
    - Comparação com Arrays e Objetos tradicionais.
- **Repositório:** `9.new-data-structures`
- **Estrutura:** `index.html`, `src/lesson9.js` (exemplos práticos).
