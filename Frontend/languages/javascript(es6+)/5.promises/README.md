**Lição 5: JavaScript Assíncrono: Promises**

- **Tema:** Lidando com operações que levam tempo.
- **Objetivo:** Entender o conceito de assincronicidade e como `Promises` ajudam a gerenciar o fluxo de código assíncrono.
- **Conteúdo:**
    - Problema do "Callback Hell".
    - O que são `Promises` (estados: pending, fulfilled, rejected).
    - Métodos `.then()`, `.catch()`, `.finally()`.
    - `Promise.all()` para múltiplas promessas.

- **Estrutura:** `index.html`, `src/lesson5.js` (exemplos com `setTimeout` e simulação de `Workspace`).
