**Lição 10: Projeto Final: Consumindo uma API com JavaScript Moderno**

- **Tema:** Integrando todos os conhecimentos para construir uma aplicação interativa.
- **Objetivo:** Desenvolver uma pequena aplicação web que consome dados de uma API pública usando `Workspace`, `async`/`await`, desestruturação e métodos de array para exibir as informações no DOM.
- **Conteúdo:** Criação de uma página HTML com inputs e um botão. Lógica JavaScript para fazer a requisição à API (ex: API de filmes, receitas, posts) e exibir os resultados de forma dinâmica.
- **Repositório:** `10.final-project-api-consumer`
- **Estrutura:** `index.html`, `style.css`, `src/app.mjs` (com a lógica principal), `src/api-service.mjs` (para modularizar a chamada da API, usando `import`/`export`).
