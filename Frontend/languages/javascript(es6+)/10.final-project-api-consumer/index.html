API Consumer

Este é um projeto final que consome uma API e exibe os dados retornados.

O projeto utiliza JavaScript ES6+ e a API JSONPlaceholder para demonstrar como consumir uma API e exibir os dados na página.

A API JSONPlaceholder é uma API falsa para testes e protótipos, que fornece dados fictícios para simular uma API real.

O endpoint utilizado neste projeto é todos, que retorna uma lista de tarefas (todos) fictícias.
