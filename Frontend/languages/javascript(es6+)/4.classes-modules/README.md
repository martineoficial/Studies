**Lição 4: Classes e Módulos (Organizando seu Código)**

- **Tema:** Programação Orientada a Objetos com `Classes` e organização com `ES Modules`.
- **Objetivo:** Criar `Classes` para definir "plantas" de objetos e usar `import`/`export` para modularizar o código.
- **Conteúdo:**
    - Sintaxe `class`, `constructor`, métodos.
    - Herança (`extends`, `super`).
    - `import` e `export` para módulos JavaScript nativos (ESM).
- **Repositório:** `4.classes-modules`
- **Estrutura:** `index.html` (com `<script type="module">`), `src/Person.js`, `src/Student.js`, `src/main.mjs`.
