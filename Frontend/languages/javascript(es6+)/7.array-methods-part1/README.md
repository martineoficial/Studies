**Lição 7: Métodos de Array Essenciais (`map`, `filter`, `forEach`)**

- **Tema:** Manipulando arrays de forma funcional e eficiente.
- **Objetivo:** Dominar os métodos mais usados para iterar, transformar e filtrar arrays.
- **Conteúdo:**
    - `forEach()`: Iteração simples.
    - `map()`: Transformação de elementos para um novo array.
    - `filter()`: Criação de um novo array com base em uma condição.
- **Repositório:** `7.array-methods-part1`
- **Estrutura:** `index.html`, `src/lesson7.js` (exemplos com arrays de objetos).
