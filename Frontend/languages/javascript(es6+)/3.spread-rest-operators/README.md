**Lição 3: Operadores Spread e Rest (Coleções Flexíveis)**

- **Tema:** Expansão e coleta de elementos em arrays e objetos.
- **Objetivo:** Dominar os operadores `Spread` e `Rest` para clonar, combinar e passar argumentos de forma flexível.
- **Conteúdo:**
    - `Spread operator` para arrays (copiar, concatenar, adicionar elementos).
    - `Spread operator` para objetos (copiar, mesclar).
    - `Rest parameters` em funções (coletar argumentos em um array).
- **Repositório:** `3.spread-rest-operators`
- **Estrutura:** `index.html`, `src/lesson3.js`.
