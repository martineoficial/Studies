# 1.modern-basics

**Lição 1: Primeiros Passos no JavaScript Moderno (`let`, `const` e `Arrow Functions`)**

- **Tema:** As novas bases do JavaScript ES6+.
- **Objetivo:** Entender a diferença entre `var`, `let` e `const` para declaração de variáveis e dominar a sintaxe e o contexto de `this` em `Arrow Functions`.
- **Conteúdo:**
    - Escopo de bloco vs. escopo de função (`var` vs `let`/`const`).
    - Imutabilidade com `const`.
    - Sintaxe concisa de `Arrow Functions` e como elas mudam o `this`.
- **Repositório:** `01.modern-basics`
- **Estrutura:** `index.html`, `src/lesson1.js`.
